# WNY Mold Dogs Website

## 1. Project Description
WNY Mold Dogs is a professional K9 mold detection service based in Western New York. The website serves as the primary online presence for the business, allowing homeowners and buyers to learn about the service, meet Liberty (the German Shepherd detection dog), and book inspections. The target audience is Western NY homeowners, home buyers, and real estate agents.

## 2. Page Structure
- `/` - Home (hero, service highlights, how it works, booking CTA)
- `/about` - Meet Liberty (Liberty profile, training, photo gallery)
- `/services` - Services (pricing, service types, service area, booking form with waiver)
- `/faq` - Frequently Asked Questions

## 3. Core Features
- [x] Homepage with hero section and booking CTA
- [x] Meet Liberty page (dog profile, credentials, real photos)
- [x] Services page with pricing ($499 / $749 / custom quote)
- [x] Booking form with square footage field and liability waiver
- [x] FAQ section (standalone page + embedded in Services)
- [x] Photo gallery with real Liberty photos
- [x] Contact info display (phone, email)

## 4. Data Model Design
No database needed at this stage. Booking data will be handled via form submission.

## 5. Backend / Third-party Integration Plan
- Supabase: Not needed initially
- Shopify: Not needed
- Stripe: Not needed
- Booking Form: Custom form with date/time picker

## 6. Development Phase Plan

### Phase 1: Core Pages UI ✅
- Goal: Build all pages (Home, Meet Liberty, Services, FAQ) with full design and content
- Deliverable: Fully designed, navigable website with real content

### Phase 2: Booking + Polish ✅
- Goal: Add booking form with liability waiver, square footage validation, promo codes

### Phase 3: Photo Gallery & Rebrand ✅
- Goal: Add real photos of Liberty, remove handler-centric branding, reframe around the dog
- Deliverable: Production-ready website centered on Liberty and the K9 service
